# Local Cyber report

Call the assessment a run.

Review coverage, evidence, and findings together. State tested and untested
scope, blocked or skipped checks, unresolved candidates, discovery limits, and
findings not retested. A complete ledger is not proof that supplied scope was
covered; do not describe incomplete evidence as clean.

Write `INDEX.md` with the target and scope, tested areas, confirmed findings,
remediation, evidence references, and limitations. Explain changes from prior
runs: findings that still reproduce, were resolved by a fresh retest, or were
not retested. Link evidence files and cite relevant source paths and lines;
include redacted proof and expected versus observed behavior.

Follow report preferences in the run brief. Keep an unfinished draft in the
workspace; create requested PDF or DOCX files locally, validate them, then
publish the completed artifact by renaming it into the evidence directory.
Install missing report libraries in a workspace virtual environment.
Render the pages and check for clipped text, overflowing tables, and unreadable
proof. Inspect the page images; text bounds alone miss broken pagination.
Use the document library's table layout to keep rows together and wrap cells.
Upload final artifacts with `cloudthinker cyber run evidence`. Keep credentials
and unredacted secrets out of every artifact.

Before settling, confirm coverage and candidate outcomes, upload final evidence,
and check the returned run state. Report what was verified and what remains
untested.
